Try the echo commands

Open the widget, then send any of these. Each exercises a different part of the protocol.

anything — echoed back as markdown

/options — option chips

/multi — multi-select + confirm

/card — card with image + actions

/carousel — three scroll-snapped cards

/links — link list

/form — inline form

/notice — a warning notice

/slow — 3s delay (typing indicator)

/long — long markdown (scrolling)

/multipart — two messages at once

/error — a connector error, handled in place

Also try the home-screen tiles: Get a quote runs a three-step flow entirely in the browser — no server call until it finishes — and Book a visit opens a configured inline form.
